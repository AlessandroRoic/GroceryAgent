## Agent skills

### Engineering standards

Before changing code, tests, dependencies, or tooling, read `CODING_STANDARDS.md`.
Apply the latest-stable tooling policy project-wide and run `npm run check` before review.

### Issue tracker

Issues live in GitHub Issues for AlessandroRoic/GroceryAgent.
Before reading or publishing issues, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels.
Before triaging issues, read `docs/agents/triage-labels.md`.

### Domain docs

This repo uses a single-context layout.
Before exploring domain concepts or architecture, read `docs/agents/domain.md`.
